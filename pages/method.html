DOMAIN INTEGRATED DESIGN (DID) / EXPANDABLE DID (xDID)

The core of the DID / xDID methodology is a structured classification, mapping and combination of functional morphological features from biological organisms. Unlike the other methodologies, DID / xDID focus on the systematic exploration of morphological features across diverse biological domains. This approach enables the generation of novel multifunctional design concepts by integrating features based on their geometric characteristics and functional capabilities.

MORPHOLOGY-DRIVEN APPROACH

Biological organisms achieve a vast array of functions through a combination of their morphology (structure), physiology (how they work), and behavior as depicted in Figure 3. The DID/xDID approach specifically focuses on functions derived from morphological features, referred to as embodiment functions.

DIVERSITY-ENHANCED

Nature often provides efficient solutions. Distantly related organisms, despite distinct evolutionary paths, frequently converge on similar structural designs to perform the same functions. DID/xDID uses this principle to explore morphological diversity across both plant and animal kingdoms, substantially expanding the design solution space for engineering challenges.

METHODOLOGY

The MBID ideation system integrates the DID / xDID methodology with BIKAS knowledgebase. Figure 4 illustrates the core components of the system, covering identification, extraction and abstraction, classification and mapping, develop–visualise–analyse, selection, and combination.

1. IDENTIFY

Identifying the organisms exhibiting various functions through their morphological features by drawing information from published articles and case studies in scientific literature.

2. EXRACT AND ABSTRACT

Each biological (morphological) feature is meticulously mapped to its corresponding function and the tissue (material) from which it originates. Furthermore, the embodiment function achieved by a feature is understood as a blend of its integrated structure and its structural strategy (configuration).

2.1 EMBODIMENT FUNCTION

The embodiment function is a synergistic outcome of an integrated structure and its structural strategy. Figure 5 is a schematic illustrating the embodiment function of a lotus leaf in repelling water. This function results from a combination of micro/nano projections (integrated structure) on the leaf's surface and the arrangement of these micro/nano structures (structural strategy). The material composition, such as the wax layer, also plays a crucial role in this function.

Integrated structure refers to the physical description of a multiscale structure. This includes details like micro/nanostructure, macrostructure, and even the presence of features like wax layers.

Structural strategy defines the integrated structural configuration. This encompasses aspects such as the arrangement, packing, or orientation of micro/nanostructures, symmetry, asymmetry, or tessellation patterns. It also accounts for changes in structural configuration due to external stimuli, such as the erection of scales or a change in skin compliance, which occur when other elements interact with the structure. 3. CLASSIFY AND MAP

The morphological features are identified, abstracted, mapped, and classified based on their shared morphological (geometric) characteristics, referred to in this research as Domains. These Domains represent overarching architectural (geometric) designations that guide the classification process and include: Surfaces, Cellular Structures, Cross-sections, and Shapes. The domain set is intentionally expandable, allowing new categories to be introduced as the system evolves. 4. DEVELOP, VISUALISE AND ANALYSE

The BIKAS knowledge base within the MBID ideation system currently comprises 60 biological features, abstracted, classified, and mapped according to shared geometric characteristics, and continues to expand. To support intuitive exploration, these features are visualised using tree dendrograms, enabling systematic selection and combination

5. SELECT

In nature, multiple features can share similar geometric characteristics and deliver the same function. For example, both shark skin and dolphin skin contribute to drag reduction. When selecting between such alternatives, MBID applies meta-level design parameters and explicit design criteria. Table 3 presents the quantitative parameters used to discriminate between features with comparable functions and overlapping geometric characteristics or domains.

Criterion 1: For multifunctional applications where one function involves anti-adsorption, absorption, repulsion, or reduction, select features with a lower total interaction area for combination.

Criterion 2: For multifunctional applications where one function involves adsorption, absorption, or attraction, select features with a higher interaction area for combination.

5.1 QUALITATIVE PARAMETERS

In addition to quantitative parameters, users may apply qualitative criteria, including the intended environmental context, to guide feature selection. Designs for arid regions, for instance, can prioritise environment-specific biological adaptations. These meta-level design parameters represent an initial baseline and will be extended as the system develops.

6. COMBINE

The morphology matrix is used to combine different morphological features systematically.

MORPHOLOGY & MULTIFUNCTIONS

Some morphological features are inherently multifunctional. Animal exoskeletons, for example, simultaneously provide fracture toughness, thermal regulation, and camouflage. Although such functions may coexist or compete, MBID systematically combines multiple morphological features to generate engineering structures with integrated function combinations that extend beyond simple coexistence or trade-offs.
