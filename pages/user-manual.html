USER MANUAL

This section presents a step-by-step guide for generating multifunctional designs using the MBID ideation system, which integrates a structured design methodology (DID / xDID) with a morphologucical knowledge base (BIKAS). The process can be supplemented with external resources such as Ask Nature, which provide curated biological strategies and application-oriented examples. These resources function as auxiliary references, offering visual cues and biological context during ideation.

At its core, the MBID system relies on a methodical framework that guides the exploration and integration of functional morphologies. This framework employs structured graphical mapping and representations to support the systematic yet creative generation of multifunctional designs.

EXAMPLE WALKTHROUGH

Non-pneumatic tires: Space / Extreme-weather robots

Design a multifunctional non-pneumatic tire for space or extreme-weather robots that: "manages variable friction" and "resists impact"

Step 1: Choosing relevant Domains

The initial selection of domains for integration is driven by two key factors: the designer's specific intention for the concept and the overarching requirements of the design problem at hand.

Step 2: Explore domain dendrograms

Surfaces Domain

To match the function manage variable friction with a biological feature, snakeskin texture can be selected. Its performance arises from an integrated structural design comprising triangular microstructured scales and a distinct structural configuration that includes longitudinal pits, caudal elevation, and directional anisotropy of the microstructures

Cellular structures Domain

To match the function resist impact with a biological feature, the woodpecker beak can be selected. Its performance is enabled by an integrated structure consisting of a trabecular foam core sandwiched between hard outer shells, combined with a graded structural configuration featuring variable porosities: outer (30%), middle (65%), and inner (30%).

Step 3: Select features using meta-level design parameters

Multiple biological features may realise the same function. As shown in Figure 7, both the woodpecker beak and pomelo peel exhibit the resist impact function and fall within the cellular structures domain. To select between features sharing the same geometric domain and function, quantitative meta-level design parameters are defined and listed in Table 4. Feature selection is then guided by applying the appropriate design criteria:

Criterion 1
For any multifunctional application, if one of the multifunction is described as an anti-adsorption / absorption or repulsion or reduction, select the features with a lower total interaction area for combination.
Criterion 2
For any multifunctional application, if one of the multifunction can be described as adsorption/absorption or attraction, select the features with a higher interaction area for combination.

For cellular structures, the woodpecker beak is selected due to its high interaction area and low porosity at the contact interface.

Qualitative parameters

In addition to quantitative parameters, users may apply qualitative selection criteria such as the intended environmental context. For example, designs intended for arid regions can prioritise biological features adapted to dry environments.

Example Output: Non-pneumatic multifunctional bio-inspired tire design

Figure 9 presents a conceptual sketch of a multifunctional non-pneumatic tyre design. The design integrates snakeskin-inspired surface features for friction management with a woodpecker-beak-inspired internal structure for impact resistance. This configuration is suited for operation in high-terrain environments.

MORE MULTIFUNCTIONAL BIO-INSPIRED STRUCTURAL CONCEPTS

Figure 10 presents schematics of multifunctional bio-inspired conceptual designs developed using the MBID ideation system. (a) Painless sutures for medical applications, created by integrating porcupine quill barbs (surface features) with the rotational parabolic cross-section of a kingfisher beak. (b) Skins for marine applications, developed by combining a honeycomb cellular structure with shark skin surface features. (c) Heat-absorption structures for aerospace applications, generated through the integration of camel nostril cross-sections and micro-bumps inspired by the Namib desert beetle surface. (d) Protective helmets for sports applications, designed by integrating a penguin-inspired spindle shape, a luffa sponge cellular structure, and a corrugated conical form inspired by Balanus.
